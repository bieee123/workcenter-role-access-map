Detailed Permission Semantics
How each access symbol behaves in the application
✓ — Full access
Role passes requireUser([...]), can open the page and perform all available actions. The menu also appears in the sidebar.
– — Denied
Role is rejected by requireUser. Direct URL access redirects to /access-denied and the menu is hidden.
✓* — Approval filtered
The approval page is accessible, but reports are filtered by role stage, decision status, and assigned workcenter where applicable.
✓ (scope)
Only assigned workcenters. Applies to INSPECTOR and LEADER; assignments are configured by Admin in /admin/users.
✓ (sendiri)
Only the user's own operator submission. OPERATOR can edit only OperatorSubmission.userId records created by the local application (source_type = LOCAL_APP).
Approval filtering
INSPECTOR sees pending QC Inspector reports in assigned workcenters; PRODUCTION_SPV/LEADER see Draft reports. ADMIN and VIEWER have no approval stage, so their “Perlu tindakan saya” tab remains empty.

Approval Page Filtering
  • ADMIN / VIEWER: no approval stage → “Perlu tindakan saya” is always empty.
  • INSPECTOR: only reports at Menunggu QC Inspector, limited to assigned workcenters.
  • PRODUCTION_SPV / LEADER: see reports with Draft status.
  • All approval roles: only reports that have not yet been decided by that user are actionable.
Account Creation
Who can create which roles
ADMIN
Can create and modify all roles directly through /admin/users, plus send invitations for all roles. Manages invitation permissions and workcenter assignments.
LEADER / PRODUCTION_SPV
Can create/invite Operator only through /operator-invitations.
Other roles
No account creation permission.
Workcenter assignment
INSPECTOR and LEADER are assigned workcenter scopes managed by Admin in /admin/users.
System Behavior
Documented automatic routing and access behavior
  • Login OPERATOR → automatically goes to Input produksi.
  • Login role pemeriksa (Leader / Prod SPV / Inspector / QC) without signature → redirected to Tanda tangan.
  • New account / credential change → redirected to Ganti sandi.
  • INSPECTOR & LEADER are restricted to assigned workcenters, configured through /admin/users.
  • Monitoring is available only to Admin, Leader, Prod SPV, Inspector, QC SPV, and QC Dept Head.
  • Denied pages redirect the role to /access-denied, while the corresponding sidebar menu is hidden.
  • OPERATOR edit scope: only own OperatorSubmission.userId records and only records with source_type = LOCAL_APP.
